Étape 2 sur 5

Configurer Firebase

Firebase stocke les demandes d'impression en temps réel. Suivez ces étapes.

Guide de création
Allez sur console.firebase.google.com et connectez-vous avec un compte Google.
Cliquez sur Créer un projet, donnez-lui un nom (ex: impression-tabac-gare), désactivez Analytics, puis cliquez Créer.
Dans le menu gauche, allez dans Firestore Database → Créer une base de données → mode Test → région eur3 (europe-west).
Dans Authentication → Sign-in method → activez Anonyme.
Dans ⚙️ Paramètres du projet → Général → Vos applications → cliquez sur </> → nommez l'app → copiez le bloc firebaseConfig.
Dans Firestore → Règles, remplacez le contenu par les règles ci-dessous puis cliquez Publier.
Dans ⚙️ Paramètres du projet → Comptes de service → Générer une nouvelle clé privée. Un fichier JSON est téléchargé : gardez-le, il sera demandé à l'étape 4.

Étape 3 sur 5

Configurer le stockage

Trois services sont nécessaires pour stocker les fichiers des clients.

1 — Uploadcare (pour les PDFs)
Créez un compte gratuit sur uploadcare.com
Allez dans Settings → API Keys et copiez la Public Key
Visible dans Settings → CDN ou dans l'URL d'un fichier uploadé.
2 — ImgBB (pour les images JPG/PNG)
Créez un compte gratuit sur imgbb.com
Allez dans API (en haut à droite) → Get API key
